# Let's alarm 발표자료 3장 시각 시안 설계

## 목적과 범위

기존 텍스트 초안 PPTX 중 대표 슬라이드 3장을 먼저 재디자인하여 전체 발표자료에 적용할 시각 방향을 검증한다. 대상은 `표지`, `주요 UI 기능`, `전체 시스템 구조도`이며, 나머지 슬라이드는 이 시안 확정 후 확장한다.

## 선택한 방향

화이트 중심의 정보 전달형 레이아웃에 그린 포인트와 제한적인 확산 그라데이션을 사용한다. 참고 이미지의 브랜드 가이드 분위기는 반영하되, 장식적 요소보다 발표 화면에서의 가독성과 구조 설명을 우선한다.

## 디자인 토큰과 서체

| 항목 | 기준 |
| --- | --- |
| 비율 | 와이드스크린 16:9 |
| Primary | `#386948` |

| Background | `#f7faf4` |
| Surface | `#ffffff` |
| Text | `#2c342e` |
| 제목 서체 | `KIMM_bold.ttf`, 필요 시 `KIMM_Light.ttf` |
| 본문 서체 | `에이투지체-4Regular.ttf`, 강조는 `에이투지체-6SemiBold.ttf` 또는 `7Bold.ttf` |

사용자가 제공한 TTF는 시안 제작 입력 자산으로 사용한다. 발표 PC에서 서체가 설치되지 않을 수 있으므로, 최종 확정본은 PDF도 함께 출력하는 것을 전제로 한다.

## 슬라이드 설계

### 1. 표지

- 좌측에 제목 `Let's alarm`과 부제 `Android 우선 실시간 동기화 알람 앱`을 크게 배치한다.
- 우측에는 실제 앱 화면을 넣을 스마트폰 형태의 플레이스홀더를 둔다.
- 배경은 흰색을 기본으로, 우측 또는 좌하단에 `#b9efc5`에서 투명으로 사라지는 부드러운 그린 그라데이션을 사용한다.
- 하단에는 `UI/UX 프로그래밍`, `6조`, 팀원 역할을 최소 텍스트로 정리한다.

### 2. 주요 UI 기능

- 실제 앱 캡처가 들어갈 두 개의 큰 프레임을 중심으로 구성한다: `AlarmHomeScreen`, `AlarmEditorSheet / AlarmRingScreen`.
- 장문의 설명 대신 `알람 관리`, `요일·소리·스누즈 설정`, `울림 종료`, `그룹 동기화`를 라벨 또는 짧은 도형 블록으로 표현한다.
- 그린 강조는 선택된 라벨, 가는 연결선, 섹션 번호에만 사용하여 화면 캡처가 주인공이 되게 한다.

### 3. 전체 시스템 구조도

- 텍스트 문단 대신 `기기 A -> Firebase Cloud -> 기기 B`의 단방향 주 흐름을 큰 블록과 화살표로 표현한다.
- Firebase 영역은 `Authentication`, `Cloud Firestore`, `Cloud Functions`, `FCM`으로 나누고, 기기 내부에는 `Flutter Android 앱`과 `Android 로컬 예약 / 정각 울림`을 둔다.
- 하단 강조 문장으로 `FCM은 동기화 신호를 전달하고, 실제 알람 울림은 Android 로컬 예약이 담당합니다.`를 표시한다.
- 기존 FigJam 도식은 참조할 수 있으나, 시안 PPTX에서는 발표용 읽기 크기에 맞춘 네이티브 도형으로 재구성한다.

## 제작 및 검증

- 제작 산출물은 `presentation/` 아래 별도의 3장 시안 `.pptx`와 편집 가능한 `.js`로 저장한다.
- 기존 8장 텍스트 초안 파일은 덮어쓰지 않는다.
- 생성 소스는 PptxGenJS와 레이아웃 경고 도구를 사용해 슬라이드 경계 초과 및 의도치 않은 겹침을 확인한다.
- 가능하면 렌더링 이미지를 생성해 한글 글꼴, 그라데이션, 도형 정렬을 시각 확인한다. 렌더 도구가 없는 경우 그 제한을 명확히 보고한다.

## 완료 조건

3장 시안 PPTX가 16:9로 생성되고, 제목/본문 서체 체계와 Stitch 색상이 적용되며, 구조도 장에서 동기화와 실제 울림의 역할 구분이 발표 화면에서 읽을 수 있게 표현되어야 한다.
